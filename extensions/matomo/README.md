# Hermes-matomo

Optional Hermes extension for Matomo self-hosted or Cloud Reporting API (optional).

## Install

Bash:
    ./extensions/matomo/install.sh

PowerShell:
    ./extensions/matomo/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for matomo.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need matomo data sources.
