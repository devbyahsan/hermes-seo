# Hermes-unlighthouse

Optional Hermes extension for Unlighthouse screenshot generation (optional).

## Install

Bash:
    ./extensions/unlighthouse/install.sh

PowerShell:
    ./extensions/unlighthouse/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for unlighthouse.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need unlighthouse data sources.
