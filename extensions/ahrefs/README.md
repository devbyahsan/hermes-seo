# Hermes-ahrefs

Optional Hermes extension for Ahrefs backlink & keyword data integration (optional).

## Install

Bash:
    ./extensions/ahrefs/install.sh

PowerShell:
    ./extensions/ahrefs/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for ahrefs.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need ahrefs data sources.
