# Hermes-bing-webmaster

Optional Hermes extension for Bing Webmaster Tools API integration (optional).

## Install

Bash:
    ./extensions/bing-webmaster/install.sh

PowerShell:
    ./extensions/bing-webmaster/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for bing-webmaster.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need bing-webmaster data sources.
