# Hermes-profound

Optional Hermes extension for Profound analytics integration (optional).

## Install

Bash:
    ./extensions/profound/install.sh

PowerShell:
    ./extensions/profound/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for profound.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need profound data sources.
