# Hermes-firecrawl

Optional Hermes extension for Firecrawl full-site crawling and site mapping (optional).

## Install

Bash:
    ./extensions/firecrawl/install.sh

PowerShell:
    ./extensions/firecrawl/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for firecrawl.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need firecrawl data sources.
