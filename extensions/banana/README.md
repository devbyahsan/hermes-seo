# Hermes-banana

Optional Hermes extension for Banana analytics integration (optional).

## Install

Bash:
    ./extensions/banana/install.sh

PowerShell:
    ./extensions/banana/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for banana.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need banana data sources.
