# Hermes-seranking

Optional Hermes extension for Seranking SEO platform integration (optional).

## Install

Bash:
    ./extensions/seranking/install.sh

PowerShell:
    ./extensions/seranking/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for seranking.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need seranking data sources.
