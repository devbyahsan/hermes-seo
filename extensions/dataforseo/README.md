# Hermes-dataforseo

Optional Hermes extension for DataForSEO API integration: live SERP, keyword, backlink, local SEO data (optional).

## Install

Bash:
    ./extensions/dataforseo/install.sh

PowerShell:
    ./extensions/dataforseo/install.ps1

## Usage

When installed, the extension adds Hermes skills and tools for dataforseo.
Invoke via Hermes commands.

## Notes

This extension is optional. Install only when you need dataforseo data sources.
